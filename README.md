# AgentTrace CLI (의사결정 추적 도구)

LLM Agent와 협업하는 소프트웨어 개발 과정에서 코드 변경의 이유(Why)와 작업 내용(What)을 구조화된 마크다운 로그로 자동 기록하고 Git 커밋과 연동하는 경량 CLI 도구입니다.

## 주요 기능
- 터미널 명령어 기반 `Why-What` 의사결정 로그 자동 생성 (`trace_log.md`)
- 타임스탬프 기반 작업 이력 추적성(Traceability) 확보
- `--commit` 옵션을 통한 Git 형상 관리 자동 연동
